Invoksa offers two AI-powered endpoints that turn a plain-text description of your work into structured invoice content. Describe the services you performed and the API suggests line items with quantities and prices — all in the language and currency you specify. Review the results before saving them as a real invoice.

## Endpoint 1 — Structured Invoice Object

```
GET /api/invoices/ai
```

**Authorization:** `Bearer <token>` — required.

Returns a full invoice object with AI-populated line items, ready to review and save.

### Query Parameters

<ParamField query="description" type="string" required>
  Natural language description of the work performed. Be as specific as you like.

  **Example:** `"3 hours of UI/UX consulting and 1 logo design"`
</ParamField>

<ParamField query="lang" type="string" required>
  Language code for the generated item descriptions (e.g. `en`, `fr`, `de`, `es`). Line item text will be returned in this language.
</ParamField>

<ParamField query="devise" type="string" required>
  Currency code for pricing (e.g. `USD`, `EUR`, `GBP`). The AI uses this to suggest realistic price values.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl -G "https://your-domain.com/api/invoices/ai" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  --data-urlencode "description=Logo design and 5 hours of consulting" \
  --data-urlencode "lang=en" \
  --data-urlencode "devise=USD"
```
</CodeGroup>

### Response

Returns an invoice object with AI-populated `items`. The `id`, `number`, and `token` fields are **not** persisted — this result is transient until you save it.

```json
{
  "id": null,
  "number": null,
  "client": null,
  "total": 1250.00,
  "status": null,
  "token": null,
  "createdAt": null,
  "updatedAt": null,
  "items": [
    {
      "id": null,
      "description": "Logo design",
      "quantity": 1,
      "price": 750.00,
      "total": 750.00
    },
    {
      "id": null,
      "description": "Consulting",
      "quantity": 5,
      "price": 100.00,
      "total": 500.00
    }
  ]
}
```

<ResponseField name="items" type="array">
  AI-generated line items derived from your description.

  <Expandable title="items[] fields">
    <ResponseField name="description" type="string">AI-generated description of the product or service, written in the requested language.</ResponseField>
    <ResponseField name="quantity" type="integer">Suggested quantity inferred from your description.</ResponseField>
    <ResponseField name="price" type="number">Suggested unit price in the requested currency.</ResponseField>
    <ResponseField name="total" type="number">Line total (`quantity × price`).</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">
  Sum of all AI-generated line item totals.
</ResponseField>

<Note>
  This endpoint returns a **transient result** — nothing is saved to your account. To persist the invoice, pass the returned `items` and `total` to [POST /api/invoices](/api-reference/invoices/create) along with a `client.id` and your chosen `status`.
</Note>

## Endpoint 2 — Raw Text Response

```
GET /api/ia/invoice
```

**Authorization:** `Bearer <token>` — required.

A simpler AI endpoint that returns the generated invoice content as a plain text string rather than a structured JSON object. Useful for displaying a quick preview or processing the output yourself.

### Query Parameters

<ParamField query="description" type="string" required>
  Natural language description of the work performed.

  **Example:** `"Website redesign and 3 months of support"`
</ParamField>

<ParamField query="lang" type="string" required>
  Language code for the generated content (e.g. `en`, `fr`, `de`, `es`).
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl -G "https://your-domain.com/api/ia/invoice" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  --data-urlencode "description=Website redesign and 3 months of support" \
  --data-urlencode "lang=en"
```
</CodeGroup>

### Response

Returns a plain text string containing the AI-generated invoice content.

```
Content-Type: text/plain

1x Website redesign — $2,000.00
3x Monthly support — $300.00
Total: $2,900.00
```

---

<Warning>
  Always review AI-generated line items and amounts before sending an invoice to a client. AI suggestions may not reflect your actual rates or the full scope of work performed.
</Warning>
