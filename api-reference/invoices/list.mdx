Retrieve every invoice associated with your account in a single call. Each object in the response includes the full client profile, computed totals, current status, and all line items. To narrow results to a single client, use the `/api/invoices/client/{id}` variant described below.

## Endpoint

```
GET /api/invoices/me
```

**Authorization:** `Bearer <token>` — required.

## Parameters

This endpoint accepts no query parameters or request body.

## Example Request

<CodeGroup>
```bash cURL
curl "http://localhost:8080/api/invoices/me" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

## Response

Returns a JSON array of invoice objects. Each element follows the full `InvoiceResponse` shape.

    "number": "INV-2024-042",

## Filter by Client

To retrieve only the invoices belonging to a specific client, use:

```
GET /api/invoices/client/{id}
```

**Authorization:** `Bearer <token>` — required.

<ParamField path="id" type="integer" required>
  The numeric ID of the client whose invoices you want to retrieve.
</ParamField>

### Example Request

<CodeGroup>
```bash cURL
curl "http://localhost:8080/api/invoices/client/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

The response follows the same array-of-invoices format as `/api/invoices/me`, filtered to the specified client.
