---
title: "Quickstart: Build Your First Invoice with Invoksa"
sidebarTitle: "Quickstart"
description: "Learn how to register your account, verify your email, authenticate, create a client, and generate your first invoice with Invoksa in five steps."
---

By the end of this guide you'll have a verified Invoksa account, a JWT token, a client record, and a live invoice — all created through the API. Each step builds on the previous one, so follow them in order. You'll need `curl` or any HTTP client installed on your machine.

<Steps>
  <Step title="Register Your Account">
    Send a `POST` request to `/api/auth/register` with your username, email, and password to create a new account.

    ```bash
    curl -X POST https://your-domain.com/api/auth/register \
      -H "Content-Type: application/json" \
      -d '{
        "username": "jane",
        "email": "jane@example.com",
        "password": "securepassword123"
      }'
    ```

    A successful registration returns your new user profile:

    ```json
    {
      "id": 1,
      "username": "jane",
      "email": "jane@example.com",
      "role": "USER",
      "emailVerified": false,
      "createdAt": "2024-01-15T10:30:00"
    }
    ```

    Notice that `emailVerified` is `false` — you must verify your email before you can log in.
  </Step>

  <Step title="Verify Your Email">
    Check your inbox for a verification email from Invoksa. Click the link inside, or call the verification endpoint directly with the token from the email:

    ```bash
    curl "https://your-domain.com/api/auth/verify?token=YOUR_VERIFICATION_TOKEN"
    ```

    Once verified, your account is active and ready to use.

    <Note>
      If you don't see the verification email, check your spam folder. The verification token is single-use and may expire — re-register if needed.
    </Note>
  </Step>

  <Step title="Log In">
    Exchange your credentials for a JWT Bearer token by posting to `/api/auth/login`:

    ```bash
    curl -X POST https://your-domain.com/api/auth/login \
      -H "Content-Type: application/json" \
      -d '{
        "email": "jane@example.com",
        "password": "securepassword123"
      }'
    ```

    The response includes your token alongside your profile details:

    ```json
    {
      "token": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "user": {
        "id": 1,
        "username": "jane",
        "email": "jane@example.com",
        "role": "ROLE_USER",
        "emailVerified": true,
        "createdAt": "2024-01-15T10:30:00"
      }
    }
    ```

    <Tip>
      The `token` field is returned with a `Bearer ` prefix. Strip that prefix before using it in your `Authorization` header, then store it in an environment variable: `export TOKEN="eyJhbGci..."`. Pass it as `Authorization: Bearer $TOKEN`.
    </Tip>
  </Step>

  <Step title="Create a Client">
    Add your first client by posting to `/api/clients` with the Bearer token you received in the previous step:

    ```bash
    curl -X POST https://your-domain.com/api/clients \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{
        "name": "Acme Corp",
        "email": "billing@acme.com",
        "phone": "+1 555 000 1234",
        "address": "123 Main St, Springfield, USA"
      }'
    ```

    Invoksa returns the newly created client record:

    ```json
    {
      "id": 1,
      "name": "Acme Corp",
      "email": "billing@acme.com",
      "phone": "+1 555 000 1234",
      "address": "123 Main St, Springfield, USA"
    }
    ```

    Note the `id` — you'll need it in the next step to link this client to an invoice.
  </Step>

  <Step title="Create an Invoice">
    Create your first invoice by posting to `/api/invoices`. Use the client `id` from the previous step and include at least one line item in the `items` array. Set `status` to `400` for unpaid:

    ```bash
    curl -X POST https://your-domain.com/api/invoices \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{
        "client": { "id": 1 },
        "status": 400,
        "items": [
          {
            "description": "Website design",
            "quantity": 1,
            "price": 1200.00
          },
          {
            "description": "Hosting setup",
            "quantity": 2,
            "price": 75.00
          }
        ]
      }'
    ```

    Invoksa creates the invoice and returns its full record, including the auto-generated invoice number, public share token, and human-readable status:

    ```json
    {
      "id": 1,
      "number": "INV-0001",
      "token": "a3f8c2e1-9b4d-4f7a-8c3e-1d2f5a6b7c8d",
      "status": "unpaid",
      "client": {
        "id": 1,
        "name": "Acme Corp",
        "email": "billing@acme.com",
        "phone": "+1 555 000 1234",
        "address": "123 Main St, Springfield, USA"
      },
      "total": 1350.00,
      "items": [
        {
          "id": 1,
          "description": "Website design",
          "quantity": 1,
          "price": 1200.00,
          "total": 1200.00
        },
        {
          "id": 2,
          "description": "Hosting setup",
          "quantity": 2,
          "price": 75.00,
          "total": 150.00
        }
      ],
      "createdAt": "2024-01-15T11:00:00"
    }
    ```

    Your invoice is live. Use the `token` to share a public view with your client at `GET /api/i/{token}`, or export a PDF at `GET /api/invoices/{id}/pdf`.
  </Step>
</Steps>
