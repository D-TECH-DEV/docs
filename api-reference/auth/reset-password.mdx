Invoksa uses a two-step flow to reset passwords. First, request a reset email to verify your identity. Then submit your new password using your email address. Neither step requires authentication — you only need the email address linked to your account.

---

## Step 1 — Request a Reset Email

Send a password-reset email to the specified account address. Invoksa will deliver a message containing instructions for completing the reset.

### Endpoint

```
POST /api/auth/confirm-pwd/{email}
```

**Authentication:** None required

### Path Parameters

<ParamField path="email" type="string" required>
  The email address of the account whose password you want to reset.
</ParamField>

### Request Example

```bash
curl -X POST https://your-domain.com/api/auth/confirm-pwd/jane@example.com
```

### Response

Returns **HTTP 200** with a plain-text message confirming the reset email has been dispatched. Check your inbox and follow the instructions before proceeding to Step 2.

---

## Step 2 — Set Your New Password

Submit your new password alongside your email address to complete the reset. Use this endpoint after receiving the reset email from Step 1.

### Endpoint

```
POST /api/auth/reset-pwd
```

**Authentication:** None required

### Request Body

<ParamField body="email" type="string" required>
  The email address of the account you are resetting.
</ParamField>

<ParamField body="newPassword" type="string" required>
  Your new password. Minimum 6 characters.
</ParamField>

### Request Example

```bash
curl -X POST https://your-domain.com/api/auth/reset-pwd \
  -H "Content-Type: application/json" \
  -d '{"email": "jane@example.com", "newPassword": "newSecurePass123"}'
```

### Response

Returns **HTTP 200** with a plain-text success message confirming the password has been updated. Log in with your new credentials using [POST /api/auth/login](/api-reference/auth/login).

### Errors

| Status | Meaning |
|--------|---------|
| `400 Bad Request` | The email format is invalid or the new password is fewer than 6 characters. |
| `500 Internal Server Error` | No account is registered with the provided email address. |
