Invoksa can turn a plain-language description of work into a fully structured invoice — complete with line items, quantities, unit prices, and a calculated total. Instead of manually building each line item, you describe what was done and let the AI draft the invoice structure for you to review and save.

---

## How It Works

When you call an AI generation endpoint, Invoksa interprets your description and returns a structured invoice or invoice data containing:

- One or more line items, each with a `description`, `quantity`, and `price`
- A computed `total` per line item and an overall invoice `total`

Invoksa offers two AI endpoints with different return shapes — choose the one that fits your workflow.

---

## Endpoint 1: Structured Invoice Response

`GET /api/invoices/ai` returns a full transient `InvoiceResponse` object. The result is **not saved** — fields like `id`, `number`, `client`, and `token` are `null` until you persist the invoice with `POST /api/invoices`.

<ParamField query="description" type="string" required>
  A plain-text description of the services or products to invoice. Be as specific as possible for the best results.
</ParamField>

<ParamField query="lang" type="string" required>
  The language for the generated line item descriptions (for example, `en`, `fr`, `es`).
</ParamField>

<ParamField query="devise" type="string" required>
  The currency code for pricing (for example, `USD`, `EUR`, `GBP`).
</ParamField>

**Example request**

```bash
curl -X GET "https://your-domain.com/api/invoices/ai?\
description=Logo%20design%20and%20brand%20identity%20package&\
lang=en&\
devise=USD" \
  -H "Authorization: Bearer <token>"
```

**Example response**

```json
{
  "id": null,
  "number": null,
  "client": null,
  "total": 2350.00,
  "status": "unpaid",
  "token": null,
  "createdAt": null,
  "updatedAt": null,
  "items": [
    {
      "id": null,
      "description": "Logo design concepts and revisions",
      "quantity": 1,
      "price": 800.00,
      "total": 800.00
    },
    {
      "id": null,
      "description": "Brand identity guidelines document",
      "quantity": 1,
      "price": 950.00,
      "total": 950.00
    },
    {
      "id": null,
      "description": "Business card and letterhead design",
      "quantity": 3,
      "price": 200.00,
      "total": 600.00
    }
  ]
}
```

<Note>
  Fields like `id`, `number`, `client`, and `token` are `null` in the AI response because the invoice has not been saved yet. They are populated once you persist the invoice with `POST /api/invoices`.
</Note>

## Endpoint 2: Raw Text Response

`GET /api/ia/invoice` is a simpler endpoint that returns the AI-generated invoice data as a **raw string** rather than a structured JSON object. This can be useful when you want to display or process the text output directly without mapping it to the full invoice shape.

<ParamField query="description" type="string" required>
  A plain-text description of the services or products to invoice.
</ParamField>

<ParamField query="lang" type="string" required>
  The language for the generated output (for example, `en`, `fr`, `es`).
</ParamField>

**Example request**

```bash
curl -X GET "https://your-domain.com/api/ia/invoice?\
description=5%20hours%20of%20backend%20consulting&\
lang=en" \
  -H "Authorization: Bearer <token>"
```

The response is a plain string — not a JSON object.

## Writing Good Descriptions

The quality of the generated invoice depends heavily on how clearly you describe the work. Follow these tips to get accurate, usable results:

<Accordion title="Be specific about services rendered">
  Instead of `"design work"`, write `"UI/UX design for a three-screen mobile onboarding flow"`. The more context you provide, the more accurately the AI can break the work into meaningful line items.
</Accordion>

<Accordion title="Include quantities when relevant">
  If you billed for a specific number of hours, sessions, or units, mention them explicitly. For example: `"5 hours of backend API consulting"` or `"3 rounds of logo revisions"`. This helps populate the `quantity` field correctly.
</Accordion>

<Accordion title="Mention the currency in the description if needed">
  The `devise` parameter sets the currency, but if your description references specific amounts (for example, `"agreed rate of €150/hour"`), include them so the AI can use realistic pricing.
</Accordion>

<Accordion title="Specify language for item descriptions">
  Use the `lang` parameter to control the language of line item text. If you set `lang=fr`, the generated `description` fields in the items array will be in French — useful when your clients expect invoices in their own language.
</Accordion>

## Saving AI-Generated Invoices

The `GET /api/invoices/ai` endpoint returns a transient invoice object. To save it and attach it to a client, follow this workflow:

<Steps>
  <Step title="Generate the invoice with AI">
    Call `GET /api/invoices/ai` with your description, language, and currency. Capture the returned `items` array and `total`.

    ```bash
    curl -X GET "https://your-domain.com/api/invoices/ai?\
    description=5%20hours%20of%20backend%20API%20consulting&\
    lang=en&\
    devise=USD" \
      -H "Authorization: Bearer <token>"
    ```
  </Step>

  <Step title="Review the generated items">
    Check each line item's `description`, `quantity`, and `price` for accuracy. Adjust any values that don't match your actual work before saving.
  </Step>

  <Step title="Persist the invoice with POST /api/invoices">
    Send the reviewed data — along with a `client` reference and a `status` integer — to create the invoice.

    ```bash
    curl -X POST "https://your-domain.com/api/invoices" \
      -H "Authorization: Bearer <token>" \
      -H "Content-Type: application/json" \
      -d '{
        "client": { "id": 1 },
        "status": 400,
        "items": [
          {
            "description": "Backend API consulting",
            "quantity": 5,
            "price": 150.00
          }
        ]
      }'
    ```

    The response includes a fully populated invoice with an assigned `id`, `number`, and `token`.
  </Step>

  <Step title="Share or export the saved invoice">
    Use the returned `token` to share a public link (`/api/i/{token}`) or call `GET /api/invoices/{id}/pdf` to download a PDF.
  </Step>
</Steps>

<Note>
  AI responses may vary between requests, even for identical descriptions. Always review the generated line items and totals carefully before sending an invoice to a client.
</Note>
