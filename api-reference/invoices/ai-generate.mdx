Describe your work in plain English (or any supported language) and Invoksa uses Google Gemini to generate a structured invoice complete with line items, quantities, and prices — all in the currency and language you specify. Use this endpoint to turn a rough project summary into a ready-to-review invoice draft in seconds.

## Endpoint

```
GET /api/invoices/ai
```

**Authorization:** `Bearer <token>` — required.

## Query Parameters

<ParamField query="description" type="string" required>
  Natural language description of the work performed. Be as specific as you like.

  **Example:** `"3 hours of UI/UX consulting and 1 logo design"`
</ParamField>

<ParamField query="lang" type="string" required>
  Language code for the generated item descriptions (e.g. `en`, `fr`, `de`, `es`). Line item text will be returned in this language.
</ParamField>

<ParamField query="devise" type="string" required>
  Currency code for pricing (e.g. `USD`, `EUR`, `GBP`). The AI uses this to set realistic price values.
</ParamField>

## Example Request

<CodeGroup>
```bash cURL
curl -G "https://your-domain.com/api/invoices/ai" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  --data-urlencode "description=Logo design and 5 hours of consulting" \
  --data-urlencode "lang=en" \
  --data-urlencode "devise=USD"
```
</CodeGroup>

## Response

Returns an `InvoiceResponse`-shaped object with AI-populated `items`. The `id`, `number`, and `token` fields are **not** persisted — this result is transient until you save it.

```json
{
  "id": null,
  "number": null,
  "client": null,
  "total": 1250.00,
  "status": null,
  "token": null,
  "createdAt": null,
  "updatedAt": null,
  "items": [
    {
      "id": null,
      "description": "Logo design",
      "quantity": 1,
      "price": 750.00,
      "total": 750.00
    },
    {
      "id": null,
      "description": "Consulting",
      "quantity": 5,
      "price": 100.00,
      "total": 500.00
    }
  ]
}
```

<ResponseField name="items" type="array">
  AI-generated line items derived from your description.

  <Expandable title="items[] fields">
    <ResponseField name="description" type="string">AI-generated description of the product or service, written in the requested language.</ResponseField>
    <ResponseField name="quantity" type="integer">Suggested quantity inferred from your description.</ResponseField>
    <ResponseField name="price" type="number">Suggested unit price in the requested currency.</ResponseField>
    <ResponseField name="total" type="number">Line total (`quantity × price`).</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="number">
  Sum of all AI-generated line item totals.
</ResponseField>

<Note>
  This endpoint returns a **transient result** — nothing is saved to your account. To persist the invoice, pass the returned `items` and `total` to [POST /api/invoices](/api-reference/invoices/create) along with a `client.id` and your chosen `status`.
</Note>

<Warning>
  Always review AI-generated line items and amounts before sending an invoice to a client. AI suggestions may not reflect your actual rates or the full scope of work performed.
</Warning>
